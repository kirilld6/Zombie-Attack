<h3>Аркадная стерялка про зомби. Задача проста, надо убить максимальное кол-во зомби.
Убивая зомби вы можете получить либо аптечку либо усиление огрневой мощности персонажа.
за каждого зомби вы получаете колличестов очков, равное целой части урона убитого зомби</h3>
___
Аркада про зомби.

<h3>Функции игры:</h3>
---

1. Контроль за жизнью персонажа;
2. Добавленно несколько жизней персонажа;
3. Звуковое сопровождение действие;
4. Усиления персонажа и аптечка;
5. Смена скина персонажа и оружия при "подъеме" усиления;
6. Сохранение результата и времени по окончании игры

<h3>Управление в игре:</h3>
---

1. Для начала игры нажмите пробел
2. Для управления персонажем используйте стрелочки на клавиатуре
3. Во время игры нажмите клавишу ПРОБЕЛА, чтобы начать стрелять

___

<h3>Для корректной сборки проекта необходимо:</h3>
___

1. Установить зависимости из файла requirements.txt
2. Использовать версию интерпритатора на ниже 3.9

<h3>Структура корневого каталога:</h3>
___

| Название папки | Содержание                                                            |
|----------------|-----------------------------------------------------------------------|
| DataSave       | В директории хранится файл с результатами игры                        |
| fonts          | В директории хранятся шрифт, используемый в игре                      |
| img            | В директории хранятся изображения используемые в игре                 |
| sound          | В директории хранится звуки и музыка, используемые в игре             |
| icon           | В директории хранятся иконки в формате png, используемые в приложении |

<h3>Структура venv:</h3>
___

| Название файла       | Содержание                                  |
|----------------------|---------------------------------------------|
| requirements.txt     | Файл, с описанием зависимостей и их версии. |
| Constants            | Константы используемые в игре               |
| ZombieAttack_main.py | Файл для запуска приложения.                |
| GameClasses.py       | Описание классов использованных в игре      |
| GameFunction.py      | Описание функций использованных в игре      |
